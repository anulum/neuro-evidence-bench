# Repository boundary

Status: accepted for local tooling construction.

NEURO-EVIDENCE-BENCH owns its repository validators now. Planned domain work owns benchmark plans, metric provenance policy, executor adapters, complete results, comparison and rerun procedures. Actual measurement internals remain with their instruments; common sealing remains with the evidence toolkit and durable record storage with the Ledger.

The local descriptor is governance data. The two planned plan/result identifiers are declarations, not implemented or registered evidence formats. No model, dataset, external metric implementation, instrument internals or duplicate result database is vendored.

Later domain changes must implement their full reachable library and command surfaces, genuine public producer/consumer integration, native strict checks, meaningful coverage, documentation and comparison benchmarks. Software-only work does not claim hardware readiness or physical results.
