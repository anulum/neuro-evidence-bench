# Roadmap

Implemented governance tooling validates closed local metadata, maintained provenance, workflow policy, development dependencies, rendered documentation and repository inventory. A fixed preflight orchestrator records actual child outcomes. No benchmark is run by these controls.

Planned public operations are plan, run, verify, report and compare. A rerun uses explicit execution and produces a new immutable result with its own source and operating context. Browsing, reporting and unrelated source changes do not automatically queue measurement.

Five planned metric families are correctness, footprint, sparsity, latency and energy per inference. Metric definitions retain their exact task, units, denominator, population and measurement method. Algorithmic observations cannot satisfy physical latency or energy requirements. Classifier confidence calibration cannot qualify a clock or power meter.

All planned metrics appear exactly once in a result. Complete raw samples, uncertainty, failed trials and unavailable fields remain visible. Equal-task, requested-quality, system-boundary and statistical-method compatibility precede numerical comparisons. A cost model may conclude that stochastic computing provides no benefit.

Real acceptance requires actual source-bound executors, accepted owning evidence, independent consumers and complete rerun commands. Proposed query and cost-model work derives from existing Ledger records and creates no duplicate authoritative store or hosted leaderboard.
